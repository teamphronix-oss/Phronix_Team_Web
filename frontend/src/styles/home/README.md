# Home section styles

Each Home section owns its CSS. Components import their matching stylesheet, so `layout.css` keeps shared/global styles only.

- `hero.css` → HeroSection.jsx
- `trusted-by.css` → TrustedBySection.jsx
- `about.css` → AboutSection.jsx
- `services.css` → ServicesSection.jsx
- `why.css` → WhySection.jsx
- `showcase.css` → ShowcaseSection.jsx
- `projects.css` → ProjectsSection.jsx
- `page-ecosystem.css` → PageEcosystemSection.jsx
- `powerhouse.css` + `feature-trio.css` → PowerhouseSection.jsx
- `top-features.css` → TopFeaturesSection.jsx
- `testimonials.css` → TestimonialsSection.jsx
- `pay-update.css` → PayUpdateSection.jsx
- `cta.css` → CTASection.jsx
